# Estudos de QA — Quality Assurance

Olá! Seja bem-vindo(a) ao meu repositório de estudos em **Quality Assurance (QA)**.

Sou formado em Ciência da Computação e estou desenvolvendo minhas habilidades em testes de software, buscando minha primeira oportunidade profissional na área de QA.

## 📚 O que estou estudando

- **Testes de Software:** testes funcionais, elaboração de casos de teste e identificação de bugs.
- **SQL:** consultas, filtros, ordenação, agregações e relacionamentos entre tabelas (`JOIN`).
- **Postman:** testes de APIs REST.
- **Cypress:** automação de testes web.
- **Git e GitHub:** versionamento de código e organização de projetos.

## 🎯 Objetivo

Praticar os conhecimentos adquiridos, desenvolver projetos e construir meu portfólio para oportunidades como **QA Júnior**.

## 📌 Sobre este repositório

Este espaço será atualizado conforme meu aprendizado evoluir, com exercícios, anotações e projetos práticos de testes de software.
